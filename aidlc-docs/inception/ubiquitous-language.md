# ユビキタス言語

> **状態: Step 1 承認済み（2026-07-23）** — Intent Answer を反映。

| 日本語 | 英語（コード名） | 意味 | 主な型・置き場 |
|--------|------------------|------|----------------|
| 公演 | Performance | 座席が属する 1 公演（排他の片側） | `PerformanceId` |
| 座席 | Seat | 公演内の 1 席（座席番号） | 集約または席識別子 |
| 仮押さえ | Hold | 15 分期限の一時確保。本確定前 | ドメイン状態 |
| 本確定 | Confirmed | 仮押さえを確定し、席を売止にする | ドメイン状態 |
| 空席 | Available / Free | 有効な仮押さえも本確定もない | 判定結果 |
| 期限切れ解放 | ReleaseExpired | 期限超過の仮押さえを解き、席を空ける | ユースケース |
| 二重確保 | DoubleBooking | 同一公演・同一席に有効確保が重なること | 不変条件で拒否 |
| 購入者 | Buyer | 仮押さえ／本確定の主体（v1 は ID のみ） | `BuyerId` |
| 有効 | Active | 期限前の仮押さえ、または本確定済み | 判定語 |

## 用語の注意

- 「予約」は美容室作品と混ざるため使わない（仮押さえ／本確定と呼び分ける）
- レガシーの `OK` / `sold` / `hold` / `free` は Before のゆれ。After では上表に揃える
- 画面・API・Domain・受入例示で同じ語を使う
